# AI-Based-Dental-Malocclusion-Detection-and-Teeth-Alignment-Analysis

Developed a deep learning-based system using Vision Transformer (ViT) architecture to detect dental
malocclusion (overbite, underbite, crossbite, crowding) from dental images with high classification accuracy.
Implemented advanced image preprocessing, patch embedding, attention-based feature extraction, and
evaluated performance using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix.
